2. Connect GitHub repo
3. Settings:
   ```
   Name: classchaos-backend
   Region: Singapore
   Branch: main
   Root Directory: backend
   
   Runtime: Docker
   Dockerfile Path: ./Dockerfile
   Docker Context: ./
   
   Instance Type: Free
   ```

## 🔧 Troubleshooting

### Build fails
- Check Dockerfile syntax
- Verify requirements.txt exists
- Check Docker logs in Render dashboard

### Container crashes
- Check environment variables are set
- Verify DATABASE_URL is correct
- Check application logs

### Port issues
- Render automatically sets `PORT` env var
- Our Dockerfile uses port 8000
- Render will map it correctly
